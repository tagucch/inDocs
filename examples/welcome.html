inDocs へようこそ

このページは indocs add examples/welcome.html で登録されたサンプルです。PC とスマホの両方で開いて、見え方を確かめてください。

頼み方

やりたいことClaude Code への頼み方裏で動くコマンド結果
作った HTML を読めるようにする「この HTML を inDocs に共有して」indocs add <file> --project <案件名>一覧の案件カードに新しい順で並ぶ
外出先で思いついた依頼を置くスマホのインボックスに書いて「頼む」PC で /inboxClaude Code が引き取って作業を始める
判断をスマホに回す「続きはスマホで判断する」(/mobile)indocs review push / watch承認かコメントが返るまで待つ
一覧から消す「〜のページを inDocs から外して」indocs remove <slug>一覧と配信から消える

スマホ幅ではこの表が縦積みのカードに畳まれます。PC 幅ではそのまま表で表示されます。
